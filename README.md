# Тестовое задание: Блог на чистом PHP + Smarty

Простой, с категориями, статьями, пагинацией и безопасной сортировкой. Проект построен по классической архитектуре MVC без использования фреймворков.

## Технологический стек
- **Backend:** PHP 8.2+ (ООП, паттерны MVC, Singleton)
- **Шаблонизатор:** Smarty 4.x
- **База данных:** MySQL 8.0 (связи Многие-ко-Многим)
- **Стили:** SCSS (Dart-Sass)
- **Инфраструктура:** Docker, Docker Compose

##  Быстрый запуск (В одну команду)

Для развертывания проекта не нужно устанавливать локально PHP, Node.js или Composer. Всё окружение полностью изолировано и автоматизировано внутри Docker.

Из корневой папки проекта выполните:

docker compose up -d --build

## Архитектурная структура

Проект спроектирован с учетом стандартов чистого кода и разделения обязанностей (Single Responsibility):

- `public/index.php` — единая точка входа. Инициализирует компоненты и запускает роутер.
- `core/Router.php` — независимый компонент маршрутизации. Сопоставляет URL с нужным контроллером и методом. Архитектура позволяет легко добавлять новые страницы одной строчкой.
- `core/Database.php` — обёртка над PDO, реализованная через паттерн Singleton для исключения лишних подключений к БД.
- `core/View.php` — инкапсулирует в себе конфигурацию и управление шаблонизатором Smarty.
- `src/Controllers/` — слой контроллеров. Отвечает за обработку HTTP-запросов, валидацию параметров и передачу чистых данных в шаблоны.
- `src/Models/` — слой моделей. Содержит только SQL-запросы к базе данных.
- `templates/` — TPL-шаблоны Smarty с использованием механизма наследования макетов.
- `scss/` — исходные файлы стилей (с использованием переменных и вложенности).
